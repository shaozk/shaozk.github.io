不过最终我只在本地完成了测试，没正式往官方提交 PR，只是将生成的 Formula 放在 issue 的评论中（也算是为开源做了贡献吧）。

# 前提知识

[Homebrew](https://brew.sh/) 是一个 MacOS 常用的开源包管理工具，简称 brew。提供将自己应用添加进 brew 管理的功能，完成后用户就可以直接用 `brew install <包名>` 下载你的工具了。

[Formula](https://docs.brew.sh/Formula-Cookbook#homebrew-terminology) 可以理解为 brew 定义包的方式，你需要为你的应用生成一个专有的 Formula，之后提交 PR 到 [brew 的仓库](https://github.com/Homebrew/brew)中去，等待管理人员审阅。

# 操作步骤

使用 `brew create` 命令，参数为你在 GitHub 上打包好的源码包 URL，另外增加 `--python` 选项代表指定生成 python 的 Fromula：

```bash
brew create --python https://github.com/Maciek-roboblog/Claude-Code-Usage-Monitor/archive/refs/tags/v4.0.0.tar.gz
```

执行完输入你的包名：

```bash
Formula name [Claude-Code-Usage-Monitor]: claude-monitor
```

生成对应的 Formula 文件，其绝对路径为：`/opt/homebrew/Library/Taps/homebrew/homebrew-core/Formula/c/claude-monitor.rb`。内容如下：
