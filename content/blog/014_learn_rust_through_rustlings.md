# 背景
在 Zig 创始人 Andrew Kelley 的一次采访中，主持人问到什么是学习 Zig 语言的最好方式时，Andrew 毫不犹豫地提到了 Ziglings。

Ziglings 其想法又来自 Rustlings。那么什么是 Rustlings 呢？简单来说：像闯关游戏一样，通过解决一个个代码 bug 来学习编程，每一关都对应一个语言特性，从易到难逐级递进。这样的方式，给学习编程增添了不少趣味。

# 心得

我现在已经刷完了 Rustlings 的全部习题，但我直接去阅读 Rust 开源项目仍然够呛，即使有 AI 的辅助。Rustlings 提供的样例相比实际项目使用的太少了，不过 Rustlings 的初衷只是带你入门而已，不应该期望完成了后就精通 Rust。

更重要的是我了解到了一种新的学习编程的思路，不一定一开始就要阅读书籍或文档，也可以是通过更有趣的实践方式。
